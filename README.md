# Linear Congruential Generator (LCG) - Virtual Laboratory

A responsive, interactive web-based Virtual Laboratory designed for **Cryptography & Network Security** courses to explore, calculate, visualize, analyze, and test the **Linear Congruential Generator (LCG)** algorithm.

---

## 🎯 Objectives
1. **Algorithmic Correctness**: Implement the Linear Congruential Generator recurrence relation accurately using safe BigInt modular arithmetic.
2. **Interactive Visualization**: Allow dynamic parameter adjustments ($X_0, a, c, m, N$) with real-time sequence generation, step-by-step mathematical calculations, tabular representations, time-series charts, and 2D phase-space lattice plots.
3. **Period & Cycle Analysis**: Perform Floyd's state-repetition cycle detection and evaluate the **Hull-Dobell Theorem** conditions for full period length $m$.
4. **Automated Unit Testing**: Verify implementation accuracy against predefined reference test cases with automated pass/fail assertion checking.
5. **Cryptographic Security Analysis**: Clearly analyze why LCGs are deterministic, linear, and **cryptographically insecure**.

## 📐 Mathematical Formula & Parameters

The Linear Congruential Generator generates a sequence of pseudorandom integers $\{X_n\}$ defined by the recurrence relation:

$$X_{n+1} = (a \cdot X_n + c) \pmod m$$

### Parameters Breakdown:
* **$X_0$ (Seed)**: The initial starting integer value ($0 \le X_0 < m$).
* **$a$ (Multiplier)**: Constant scaling factor ($0 < a < m$).
* **$c$ (Increment)**: Constant offset ($0 \le c < m$). When $c = 0$, the generator is known as a **Multiplicative Congruential Generator (MCG)** or Lehmer RNG.
* **$m$ (Modulus)**: Modulus defining the maximum state space size ($m > 0$).
* **$N$ (Iterations)**: Total number of pseudorandom values to generate ($1 \le N \le 1000$).
* **$U_n$ (Normalized Output)**: Floating-point pseudorandom number in $[0, 1)$ computed as $U_{n+1} = X_{n+1} / m$.

## 🔬 Algorithm & Theory

### Hull-Dobell Theorem (Max Period Conditions)
An LCG achieves a maximum full period length equal to $m$ for all seed values $X_0$ if and only if:
1. $c$ and $m$ are relatively prime ($\gcd(c, m) = 1$).
2. $a - 1$ is divisible by every prime factor of $m$.
3. $a - 1$ is divisible by $4$ if $m$ is divisible by $4$.

### Cycle Length Detection (Floyd's Algorithm)
Because the state space is finite ($\le m$), any sequence generated by an LCG must eventually repeat. The cycle length $P$ satisfies $1 \le P \le m$.

## ⚠️ Cryptographic Limitations & Security Warning

> [!CAUTION]
> **LCG IS NOT CRYPTOGRAPHICALLY SECURE!**

### Primary Vulnerabilities:
1. **Full Predictability**: Knowing 3 or 4 consecutive generated numbers allows an attacker to reconstruct $a, c, m$ in $O(1)$ time by solving a modular linear system.
2. **Marsaglia's Lattice Structure**: In $k$-dimensional space, points $(X_n, X_{n+1}, \dots, X_{n+k-1})$ fall onto a surprisingly small number of parallel hyperplanes ("RNGs fall mainly in the planes").
3. **Low-Order Bit Shortcomings**: When $m = 2^k$, the lowest $b$ bits have a period of only $2^b$. The least significant bit alternates between 0 and 1!

### Recommended Cryptographic Alternatives:
For secure cryptographic keys, nonces, and session tokens, use **Cryptographically Secure Pseudorandom Number Generators (CSPRNGs)**:
* `window.crypto.getRandomValues()` (Web Crypto API)
* **AES-CTR DRBG** (NIST SP 800-90A)
* **ChaCha20-PRNG**
